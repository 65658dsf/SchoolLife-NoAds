# 启动后正版提示并退出：定位与修复

**状态：2026-09-13，修复测试包已生成，尚待红米 K90 Max、Android 17 实测。** 首版由用户确认：出现用户协议界面后提示“请前往官方渠道下载正版APP”，随后退出。

## 原因

首版重新签名后，APK 实际证书变成测试证书，但网易保护壳的内置期望证书仍是原证书。保护壳约延迟 3 秒读取安装包证书，计算 MD5，发现不匹配就显示风险提示 0 并主动终止。17 项广告补丁离线检查和 APK 签名验证不检查这种应用内部的信任配置，所以首版通过这些检查仍会退出。

| 校验值 | MD5（DER 证书摘要） |
| --- | --- |
| 原包内置期望值 | `C62C38BE109D2A72528C307BDFC21E34` |
| 首版实际签名／修复版实际签名 | `6693563C906323213F14A44F14264E62` |
| 本次修复后的内置期望值 | `6693563C906323213F14A44F14264E62` |

完整原生证据见 [原生定位报告](D:/Coding/LemonDev/反编译/运动世界/.analysis/startup-review/strings64/native-findings.md)。其中 `0xf13bc` 为 ARM64 检查线程；`0xf14e0` 触发风险 0，经 `0x111004` 显示提示并进入原生终止流程。地址是解压后库内虚拟地址，不能直接当成 APK 文件偏移。

## 本次修改

保留首版 5 处广告入口补丁，另修改外层 `classes.dex` 的加密配置字段 `c`。配置头位于 `0x103b8`，长度为 254 字节；它保存 17 个字段，`c` 是期望证书 MD5。

将 `c` 更新为实际用于签名的本地证书摘要，并重新加密、更新外层 DEX 校验和。`c` 对应密文范围为 `0x103c2..0x103e2`（右端不含），实际变化 28 字节；加上外层校验字段，与首版 DEX 相比合计变化 52 字节。

- 另外 16 个配置字段、原字段顺序、换行和总长度保持一致。
- 原生库、签名读取与比较代码、风险提示和终止逻辑保持一致。
- 配置使用真实的测试证书 MD5，没有设置 `NONE` 或空值；其他非匹配证书仍走原拒绝分支。
- 保留 `mOfficial` 及其他环境检查、业务鉴权、登录、定位和跑步代码。
- 原始 APK 与首版 APK 保留；新包使用首版同一测试证书。

补丁源码见 [startup_fix.py](D:/Coding/LemonDev/反编译/运动世界/补丁文件/startup_fix.py) 与 [build_startupfix.py](D:/Coding/LemonDev/反编译/运动世界/补丁文件/build_startupfix.py)，实际原始／替换字节见 [启动修复清单](D:/Coding/LemonDev/反编译/运动世界/补丁文件/启动修复清单.json)。
